# R-SEARS API Documentation

This folder holds integration docs, endpoint descriptions, and external service contracts.

## API versioning
The application exposes versioned endpoints under `/api/v1`.

## Core modules
- Authentication
- Driver management
- Incident reporting
- Police response
- Hospital dispatch
- Admin analytics

## Base URL
- Local: `http://localhost:5000/api/v1`
- Production: use the configured Vercel API domain
