# System Overview

R-SEARS is a public-sector emergency response system designed for Rwanda. It supports accident detection, dispatch coordination, emergency notifications, and health-service integration in a secure and auditable environment.

## Objectives
- Reduce emergency response time
- Improve accident data quality
- Connect police, hospitals, ambulances, and dispatch centers
- Provide secure and modular integration architecture for government agencies

## Functional requirements
- Authentication for all roles
- Real-time accident alerts
- GPS and map overlays
- Dispatch assignment and routing
- Dashboard analytics
- Audit log retention
- Backup and compliance-ready reporting

## Non-functional requirements
- High availability through modular architecture
- Role-based access control
- JWT-based authentication
- Secure headers and sensitive data protection
- Support for Vercel + Neon deployment
